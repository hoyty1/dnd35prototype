# Known issues: Build, repo and tooling (REPO-)

## Development traps

- **REPO-002** · **Med** — **TextMesh Pro asset GUIDs do not match their committed metas.** The 33 files in Assets/TextMesh Pro were committed in 0089af1 without metas and reference the canonical TMP GUIDs; the metas committed on 2026-10-03 were generated locally with different GUIDs, so `TMP_Settings.defaultFontAsset` is null and the SDF material has no shader. Impact is small: only 4 UIs use TMP, and they load the font by Resources path with a legacy-font fallback. *Evidence:* Assets/TextMesh Pro/Resources/TMP Settings.asset:27; Assets/TextMesh Pro/Resources/Fonts & Materials/LiberationSans SDF.asset.meta; Assets/Scripts/UI/Combat/ActionButtonPanel.cs:1084-1090. *Fix:* in Unity, delete Assets/TextMesh Pro, re-import TMP Essential Resources (Window > TextMeshPro), and commit the folder with the canonical metas it ships with.
- **REPO-003** · **Med** — **The git index mixes 'Docs/' and 'docs/' path prefixes.** Three .md files remain under Docs/ beside lowercase docs/, the only case collision in the index, and root designs/ (2 plans) sits beside docs/designs/. On a case-sensitive filesystem a clone gets two folders and docs/X links to Docs/ files break (this Windows machine merges them). *Evidence:* `git ls-files Docs designs`; `git config core.ignorecase` (true). *Fix:* Retire or `git mv` the remaining Docs/ and designs/ files into docs/ (via a temporary name on Windows), then check `git ls-files | cut -d/ -f1 | sort -u`.
- **REPO-004** · **Med** — **No asmdefs, no test framework and no IDE package.** The manifest lacks com.unity.test-framework and an IDE package (so no .sln/.csproj), pins textmeshpro '3.2.0-pre.12' (resolved to builtin 5.0.0) and lists the unused 2d.tilemap. With no .asmdef, all ~654 .cs files (about 292K lines) compile into Assembly-CSharp, and `partial class GameManager` (52 files, 7 folders) constrains any split (tests: TST-013). *Evidence:* Packages/manifest.json, packages-lock.json; `find Assets -name '*.asmdef'` (none). *Fix:* With the owner's OK, add an IDE package, drop the pin and 2d.tilemap, and add the test framework with a Tests asmdef (compile checks: REPO-010).
- **REPO-005** · **Med** — **.gitattributes covers only shell scripts, so other line endings depend on core.autocrlf.** Since 2026-10-03 `.gitattributes` pins `*.sh` to LF (so `tools/compile_check.sh` survives checkout). Everything else still follows core.autocrlf=true: most text is stored LF and checked out CRLF, while MainScene.unity, packages-lock.json and several ProjectSettings assets stay LF. With the ~1,130 YAML metas now committed (2026-10-03), Windows and Linux diffs can be noisy. *Evidence:* `.gitattributes`; `git ls-files --eol`. *Fix:* add `* text=auto`, Unity YAML (`*.unity *.prefab *.asset *.meta *.mat`) `eol=lf` and binary rules (`*.png *.ttf binary`).
- **REPO-006** · **Med** — **Compile breakage recurs.** About 23 commit subjects mention "compil", including fixes for about 150 errors across 53 files and 127+ across 20 files (f706ac6); the System.Random vs UnityEngine.Random ambiguity alone was fixed 6 times. *Evidence:* `git log --oneline | grep -i compil`; 759c394 (broke the build until 71b869b); 4d7b66a, e9508ed. *Fix:* Run `tools/compile_check.sh` after every change and extraction step, and add `using Random = UnityEngine.Random;` wherever `System` is imported.
- **REPO-008** · **Low** — **Branch hygiene.** The local feature/monk-barbarian-classes branch holds only an empty merge commit, and older commits with vague messages ('what what', 'tes') hide real scene changes. GitHub Desktop stashes uncommitted work silently when switching branches. *Evidence:* `git branch -a`; `git log --oneline`; `git stash list`. *Fix:* delete the stale branch, commit docs separately with descriptive messages, and check `git stash list` after any branch switch.
- **REPO-009** · **Low** — **Unfinished code is not marked with TODO.** Services/, AI/, Spell/{Casting,Components,Data,Database,Domain} and Tests/ (TST-003) have no TODO, FIXME, HACK or NotImplemented markers; stubs show only as prose ("For now, we just log it", AIService.cs:3253) or SpellData.IsPlaceholder. *Evidence:* `grep -rniE 'for now|future|placeholder|reserved' Assets/Scripts/Services Assets/Scripts/AI`. *Fix:* When auditing stubs, search case-insensitively for "for now", "future", "placeholder", "reserved", "simplif" and IsPlaceholder.
- **REPO-010** · **Low** — **The headless compile check depends on Unity's last response file.** `tools/compile_check.sh` runs Unity's bundled Roslyn against the newest Library/Bee Assembly-CSharp.rsp (HEAD: 0 errors, 508 warnings), last written on 2026-05-27, so changed references or defines are missed until the Editor regenerates it. *Evidence:* tools/compile_check.sh; Logs/AssetImportWorker*.log mtimes (project-root Logs/). *Fix:* Open the Editor once whenever references or defines change.
- **REPO-011** · **Low** — **Some changes were reverted or flip-flopped.** The Summon Swarm caster exclusion changed back and forth, and the grapple submenu fix, skill costs, button sizes and token art integration were reverted. *Evidence:* b40bff9, f9e0f30, a47aae6, b0b7652 (Summon Swarm); a777586, 1c26f8e, 382d47e, 281dab7. *Fix:* Read those commits before changing these areas again.

## Dead code, duplication and tech debt

- **REPO-012** · **Low** — **Old versions of the Abacus agent blob still bloat git history.** `.abacus.donotdelete` (a 3 MB encrypted Abacus agent-state file) was untracked and added to `.gitignore` on 2026-10-03 by owner decision; the file itself stays on disk. Its ~340 committed versions still take about 421 of the 529 MiB in `.git/objects`, so clones stay large. *Evidence:* `git log --oneline -- .abacus.donotdelete | wc -l`; `git count-objects -vH`. *Fix:* only on explicit owner request: `git filter-repo --invert-paths --path .abacus.donotdelete` plus a force-push (changes every SHA; back up first).
- **REPO-015** · **Low** — **Monster Manual token art is unused for now.** Assets/StreamingAssets/CreatureTokens holds 278 PNGs (29 MB) that no code loads since the loader was reverted (281dab7); the owner decided on 2026-10-03 to keep them for future use. Note that StreamingAssets ships in every build. *Evidence:* `grep -rn CreatureToken Assets/Scripts` (none). *Fix:* when token art is wanted, write a loader (map NPC ids to `creature_manifest.json`) and curate the mismatched filenames; keep the folder README accurate meanwhile.
- **REPO-017** · **Low** — **Assets/_Recovery/0 (1).unity is a committed crash-recovery scene.** It is MainScene.unity with an older SceneBootstrap GUID; it slipped past .gitignore:55, which ignores only `Assets/_Recovery/0.unity`, and adds a confusing second scene. *Evidence:* `git ls-files Assets/_Recovery`; .gitignore:55. *Fix:* `git rm` it, delete the folder and its .meta, and replace .gitignore:55 with `/[Aa]ssets/_Recovery/`.
- **REPO-018** · **Low** — **Duplicate image assets.** Root icon_assets/ (7 PNGs) and Assets/Sprites/ (4 PNGs) are byte-identical copies of Resources sprites that nothing loads; the 17 PNGs in Assets/Resources/Icons/{Portraits,Tokens} duplicate Sprites/Icons and both paths are live, so they ship twice (UI-034). *Evidence:* Assets/Scripts/UI/Common/IconLoader.cs:30, 40, 66, 76; Assets/Scripts/UI/Common/IconManager.cs:140. *Fix:* `git rm -r icon_assets Assets/Sprites`; optionally consolidate the two Resources icon folders.
