# Tactics inventory: spells of levels 0-2

Part of the [tactics inventory](README.md): [actions](ACTIONS.md), [spells 0-2](SPELLS_0-2.md), [spells 3-5](SPELLS_3-5.md), [creatures L1-4](CREATURES_L1-4.md), [creatures L5-8](CREATURES_L5-8.md), [summons](SUMMONS.md).

**Inventory unverified except sampled.** The entries were written by agents from the SRD, the PHB and a code read; a sampled pass checked about one entry in 8 and its corrections are applied (✔). Treat unmarked rows as leads: grep the code before relying on a status. Nothing here was verified in Play mode.

A spell is listed at the lowest level it has on any PHB class or domain list. Scope: PHB spells of levels 0-4, plus 5th-level Sor/Wiz, Clr and Drd spells for enemy casters (see SPELLS_AND_METAMAGIC.md for database IDs and class lists).

204 entries: impl 63, placeholder 57, partial 48, missing 31, data only 5. AI usable: no 121, partial 71, yes 12. Priority: P1 43, P2 60, P3 101.

Columns:

- **Status:** code status (`impl`, `partial`, `data only` = data exists but nothing executes it in play, `placeholder` = log-only or flagged placeholder, `missing`), then whether a PC and the enemy AI can use it today. ✔ marks an entry corrected or confirmed by the sampled verification.
- **AI use today** and **Value model** describe what an action-catalog entry would need; they are proposals, not code.
- **Pri:** P1 matters in most level 1-8 fights, P2 sometimes, P3 rarely.
- Cells are trimmed; the full inventory (rules summary, code refs, deviations, synergies, catalog fields) is in the local work file and can be regenerated.
